# The Book Nook

> A cozy little corner of the internet for Cape Town's favorite (fictional) bookstore.

So here's the thing — I built this website for a bookstore that doesn't actually exist. The Book Nook is a made-up shop, but the code behind it is very real. This project was my way of practicing front-end development: laying out pages, making things responsive, wiring up a bit of JavaScript, and trying to make it all feel like a place you'd actually want to browse.

---

##  What's the deal with this project?

The Book Nook is a multi-page website for a fictional independent bookstore in Cape Town. In the story, it was founded back in 2012 by a former teacher named Sarah Johnson, and it's the kind of place that hosts book clubs, author talks, and Saturday morning reading sessions for kids.

In reality, it's a collection of HTML, CSS, and JavaScript files I put together to get better at building websites. There's no database, no shopping cart, no backend — just clean, hand-written code that looks nice and works well in a browser.

---

##  What can it do?

Nothing groundbreaking, but it does the basics well:

- **Looks good on any screen** — phone, tablet, or desktop, it all holds together
- **Mobile menu that actually works** — tap the hamburger icon and the nav slides open
- **Five separate pages** — Home, About, Products, Enquiry, and Contact
- **A single-page version too** — if you'd rather not click between pages, everything's combined into one file with tab-style navigation
- **Forms with basic validation** — the browser will yell at you if you forget to fill in a required field
- **An FAQ section** — click a question and the answer expands (accordion style)
- **A map placeholder** — because every contact page needs one, right?

---

##  What I used to build it

Nothing fancy. Just the fundamentals:

- **HTML5** for the structure
- **CSS3** for the styling — Grid and Flexbox did most of the heavy lifting
- **Plain JavaScript** for the menu toggle, the FAQ accordion, and the tab navigation
- **Google Fonts** — Playfair Display for headings, Lato for body text
- **Font Awesome** for the icons
- **Leaflet.js** — referenced on the contact page for maps (even if it's just a placeholder for now)

No frameworks, no build tools, no `npm install`. Just open the file and it works.
